# 优化后的提示词：中国—东盟法律法规数据库页面调整

请对现有【中国—东盟法律法规数据库】前端页面执行以下优化。该项目按**成熟、正式、已上线的官方法律数据库**呈现，所有页面文案必须正式、权威、克制，不得出现参赛、演示、原型等非正式表述。

------

## 1. 全局内容清理

- 删除所有前端可见的“参赛、比赛、演示原型、演示数据集、节选、示意文本、不构成法律意见、三审三校”等字样。
- 删除“本页面为参赛演示原型……查看数据来源清单”等提示。
- 删除“特色功能入口”整块内容。
- 删除“为什么需要这个数据库”整块内容。
- 删除“演示库统计”整块内容及所有统计数字。
- 删除底部“参赛队：上海对外经贸大学一粒橡子队”“2026年中国（广西）—东盟‘AI+法律’应用创新大赛”等相关表述。
- 页脚仅保留正式产品信息：关于我们、数据来源、使用条款、隐私政策、联系方式、友情链接、版权声明。

------

## 2. 顶部导航与品牌区

### 2.1 顶部导航精简

顶部导航栏仅保留：

- 首页
- 法律体系
- AI 问答

删除以下顶部导航项：

- 按国家
- 按类型
- 按主题
- 条款比对
- 术语库
- 高级检索

### 2.2 功能迁移

将“按国家、按类型、按主题、高级检索”迁移到首页搜索入口及搜索结果页中：

- 首页搜索框附近提供“搜索法规”入口。
- 点击进入搜索结果页后，在搜索页展示筛选条件。
- 筛选条件包括：按国家、按类型、按主题、高级检索。
- 高级检索包含：法律层级、时效性、公布日期、施行日期、制定机关、语言。

### 2.3 品牌区语言切换适配

顶部品牌区结构：

- 左侧：logo + “中国—东盟法律法规数据库”
- 中间：导航
- 右侧：语言切换、登录/用户入口

要求：

- 切换不同语言时，logo 和标题不得挤压、重叠、溢出或换行错位。
- 品牌区使用 flex 布局，logo 不压缩，标题容器设置 `min-width: 0`。
- 标题使用响应式字号：`font-size: clamp(16px, 1.6vw, 24px);`
- 标题默认 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`
- 标题过长时优先缩小字号；仍不足则省略，hover 显示完整名称。
- 语言切换器固定右侧，不占用品牌区宽度。
- 空间不足时，导航折叠为汉堡菜单，不得挤压品牌区。
- 移动端优先保证 logo 和语言切换可见，标题可省略或两行显示。
- 验收标准：任意语言下，logo、标题、导航、语言切换三者不重叠、不溢出、不错位。

## 3. 首页布局

首页保持干净、整洁、不复杂、官方。

首页结构建议：

1. 顶部导航栏：仅首页、法律体系、AI 问答。
2. Hero 区：产品名称 + 一句话定位 + 搜索框。
3. 搜索框下方：搜索模式切换，如“搜法规 / 搜案例 / 搜条约”。
4. 可选模块：最新法规 / 新法速递。
5. 底部：友情链接 + 正式页脚。

首页不得出现：

- “按国家浏览”卡片墙
- “按法律类型浏览”
- “按主题浏览”
- “特色功能入口”
- “为什么需要这个数据库”
- “演示库统计”
- 任何参赛、比赛、演示、原型相关文案

## 4. 搜索结果页

搜索结果页要求：

- 顶部保留干净导航。
- 搜索框下方或侧边提供筛选：按国家、按类型、按主题、高级检索。
- 结果列表展示：法规标题（多语言）、国家标识、法律层级、时效性、公布日期。
- 保持官方列表风格，不堆砌功能卡片。
- 高级检索可展开，不默认占用大面积首页空间。

- 蓝白主题贯穿始终。
- 约 90% 界面使用白色和浅灰，约 7% 使用蓝色。
- 蓝色仅用于导航、按钮、链接、选中态、关键标识。
- 顶部三栏布局：左品牌、中导航、右语言/用户。
- 语言切换不得影响品牌区宽度。
- 响应式断点：
  - ≥1200px：三栏布局。
  - 768–1199px：导航可折叠，筛选栏可折叠。
  - <768px：单栏布局，汉堡菜单，筛选条件以底部抽屉形式弹出。
