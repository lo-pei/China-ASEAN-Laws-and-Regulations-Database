## 一、目录结构

```
rules/
├── README.md                    ← 本文件
├── data/                        ← 数据
│   ├── index.json               ← 总索引（17,365 部法规的元数据 + 文件名）
│   ├── <法规ID>.json            ← 每法一个文件，共 17,365 个
│   └── 无本地原文清单.csv        ← 759 条「无本地条文原文」目录（仅链接，需前往官方渠道获取）
└── rules/                       ← 提取规则与工具
    ├── SKILL-条文入库与译文分离规范.md   ← 核心规范（条文契约、红线、分卷规则）
    ├── 06-全文数据规范.md                ← 全文数据结构与字段规范
    ├── 03-数据建设方案.md                ← 数据来源、清洗与归类方案
    ├── export-law-articles.js            ← 本数据集的导出脚本（可复现）
    └── verify-data.js                    ← 数据层校验器（规则的可执行版本）
```

> **导出口径**：`data/*.json` 只导出**有条文正文**的法规（即已落 A/C/B 层分卷者）。
> `intl-catalog.js` 中 `coverage: "catalog"` 的条目（仅目录 + 官方链接、无本地条文）
> 不在 `data/` 中生成单独文件，它们体现在 `无本地原文清单.csv`。老挝的 291 部 PDF-only
> 法律即属此类。

## 二、数据说明（`data/`）

### 2.1 单法 JSON 结构

文件名即法规 ID（与 `index.json` 的 `laws[].file` 对应）。以 `CN-CONST-0001.json`（中华人民共和国宪法）为例：

```json
{
  "id": "CN-CONST-0001",
  "title": { "zh": "中华人民共和国宪法（2018年修正文本）", "en": null, "orig": null },
  "country": "CN",
  "countryName": "中国",
  "layer": "cn",
  "pack": "cn-p12",
  "language": "zh",
  "level": "constitution",
  "category": "宪法",
  "status": null,
  "promulgatedDate": "1982-12-04",
  "effectiveDate": null,
  "issuingBody": "全国人民代表大会",
  "docNumber": null,
  "coverage": "full",
  "structureMode": "ARTICLE",
  "articleCount": 143,
  "chars": 14331,
  "source": { "name": "...", "url": null },
  "sourceFile": "数据资源\\法律法规（持续更新中）\\法律\\中华人民共和国宪法_20180311.docx",
  "fetchedAt": null,
  "articles": [
    { "no": 1, "noLabel": "第一条", "chapter": "第一章　总纲", "text": "中华人民共和国是工人阶级领导的……" }
  ]
}
```

**字段口径**

| 字段 | 含义 |
| :--- | :--- |
| `id` | 法规唯一 ID（稳定、不复用） |
| `title` | 名称，按语种分键（`zh` / `en` / `orig` 原文名），缺失为 `null` |
| `country` / `countryName` | ISO 二字码 / 中文国名（12 个国家，含中国） |
| `layer` | 数据所在层：`fulltext`（A 法域全文层·重点法预加载）｜`cn`（B 中国全量层）｜`intl`（C 东盟分卷层） |
| `pack` | 在库中的分卷文件名（不含扩展名） |
| `language` | 条文原文本语言（`zh`/`en`/`th`/`id`/`lo`/`vi`/`my`/`km`…） |
| `level` / `category` | 法律层级（`constitution`/`code`/`law`/`regulation`…）/ 中文分类 |
| `coverage` | `full`（有全文）｜`catalog`（仅目录）｜`excerpt`（节选） |
| `articles[].no` | 条文数字序号 |
| `articles[].noLabel` | 条文标签（如「第一条」/「Article 1」） |
| `articles[].chapter` | 所属章（有则给出，否则无此键） |
| `articles[].heading` | 条文标题（有则给出，否则无此键） |
| `articles[].text` | **条文正文，逐字原文** |

```js

```
