## 1. 视频定位与策略

### 1.1 使用场景与目标评委

| 维度 | 内容 |

## 2. 技术规格与录制准备

### 2.1 画面与浏览器规格

| 项目 | 设定值 | 说明 |
| :--- | :--- | :--- |
| 分辨率 | 1920 × 1080 | 与原型桌面三栏布局匹配，容器宽 1280px 居中不溢出 |
| 帧率 | 30fps | 页面过渡动画为 300ms，30fps 下观感顺滑 |
| 浏览器缩放 | 100%（Ctrl+0 复位） | 缩放会破坏版面比例，也会影响法条正文行高 |
| 系统显示缩放 | 100% | 若系统为 125%，先改回 100% 再录，否则画面文字发虚 |
| 浏览器窗口 | 最大化并隐藏书签栏（Ctrl+Shift+B） | 避免泄露个人书签 |
| 光标 | 系统默认箭头，可开启“显示指针位置” | 便于评委跟随点击 |

| 无关窗口 | 关闭微信、钉钉、邮件客户端及其他标签页 | 任务栏也应干净 |

| 音量 | 系统音量 60%，麦克风增益自 −12dB 起调 | 防止爆音削波 |

### 2.2 麦克风与音频

1. 使用有线耳麦或 USB 麦克风，**不要使用笔记本内置阵列麦克风**。
2. 录制前用“声音设置 → 输入 → 测试麦克风”观察电平：正常说话峰值在 **−12dB 至 −6dB** 之间。
3. 房间处理：关闭空调与风扇，拉上窗帘，桌面垫鼠标垫或布减少反射，人离墙 30cm 以上。
4. 试录 15 秒并回放，确认无电流声、无回声、无爆音。
5. 音频参数：**48kHz / 16bit / 单声道**，后期响度归一至 **−16 LUFS**，峰值不超过 **−1dBTP**。
6. 环境不可控时采用“**先录屏、后配音**”：录屏阶段完全静音，按分镜对齐动作节奏；配声阶段逐段朗读再剪辑对齐。

### 2.3 录屏与剪辑软件（免费方案优先）

| 方案 | 定位 | 关键设置 | 备注 |
| :--- | :--- | :--- | :--- |
| **OBS Studio（首选，免费开源）** | 主录屏工具 | 输出模式“高级”；录像格式 **MKV**；编码器 x264；码率 **12000Kbps** CBR；基础与输出分辨率均为 1920×1080；FPS 30；音频 48kHz；场景仅一个“显示器采集” | 先录 MKV（意外断电不废片），剪辑前无损转 MP4 |
| Windows 自带 Xbox Game Bar（Win+G） | 应急备用 | 捕获当前窗口 | 只能录单窗口，切换标签页会中断，仅作兜底 |
| 剪映专业版（免费）或 DaVinci Resolve（免费版） | 剪辑 | 工程 1920×1080 / 30fps；导出 H.264 MP4 | 剪映的语音识别字幕可生成初稿，再人工逐条校对 |

> 录制纪律：**一次只录一个镜头的素材**，每个镜头录 2 至 3 条，文件命名为 `S03_take2.mkv`，剪辑时按时间码拼接。不要试图一遍到底。

### 2.4 字幕、片头与片尾

- 字幕建议**烧制**（硬字幕），确保评委静音观看也能读懂。
- 字号 36 至 40px（1080p 下），白色字 + 60% 黑色圆角底条，底部居中；行宽不超过画面宽度 80%，单行不超过 22 个汉字，单条停留不少于 1.5 秒。
- 关键数据在字幕中用金色（`#D69E2E`）强调，与基线视觉系统一致。
- 片头 8 秒、片尾 10 秒模板见第 5 节；只用纯色底 + 文字 + 淡入淡出，不使用外部素材。

### 2.5 原型演示数据与“演示账号”说明

1. 原型是**零依赖静态站点**（`prototype/index.html`），双击即可运行，**无需注册、无需登录、没有演示账号**。本脚本不使用任何账号密码，也不出现“登录成功”类画面。
2. 顶部导航右端为**界面语言切换**与**深色/浅色模式切换**按钮，本脚本不涉及任何登录、注册或权限操作。
3. 演示数据为**原型内置演示数据集**：12 法域、67 部法规、302 条条文、161 条术语；条文为**节选或示意文本**，画面必须出现“演示数据”标识，旁白必须说明“不构成法律意见”。
4. 演示涉及的具体法规一律写明国别、名称与文号（基线第 11 节第 3 条要求），本脚本统一使用以下三条：
   - 越南《投资法》（Luật Đầu tư，61/2020/QH14），法规 ID `VN-INVEST-2020`；
   - 中国《外商投资法》（法规 ID `CN-FIL-2019`），作为对照基准；
   - 新加坡《1967年公司法》（Companies Act 1967，法规 ID `SG-COMPANIES-1967`），用于三栏比对。
5. 上述文号与条文序号已与 `prototype/data/dataset-core.js` 核对一致；若后续数据集更新，须同步修改本脚本第 3、4、6 节（这是数据核验动作，不改变分镜结构）。
6. 录制使用**全新无痕窗口**，提前清空地址栏历史与自动补全，避免联想词泄露个人搜索记录。

### S04｜M1 多语种智能检索：关键词与语义　00:42—01:02　（20 秒）
