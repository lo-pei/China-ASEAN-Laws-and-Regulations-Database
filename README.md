## 一、这是什么

本项目交付一套**可交互的 Web 产品原型**，覆盖六大核心模块，并配套完整的技术架构文档、视觉设计规范、数据建设方案、演示视频脚本与项目申报书正文。

| 模块 | 名称 | 原型入口 |
| :--- | :--- | :--- |
| M1 | 多语种法律智能检索 | `#/search` |
| M2 | 东盟11国法律分类浏览 | `#/browse/country`、`#/browse/type`、`#/browse/topic`、`#/systems` |
| M3 | 跨语言法律条款智能比对 | `#/compare` |
| M4 | 多语种法律术语即时翻译 | `#/terms`（法规详情页内经正文悬停触发） |
| M5 | 法规详情页与阅读体验 | `#/law/:id` |
| M6 | AI 法律问答助手 | `#/assistant` |

## 三、如何运行原型（零依赖、可完全离线）

**方式一：直接打开**

双击 `prototype/index.html`，用 Chrome / Edge / Firefox 打开即可。原型为**零依赖静态站点**（无构建、无 CDN；**除用户主动开启的 BYOK 模型增强外无任何外网请求**），可离线运行，也便于复制到 U 盘用于现场答辩演示。

**方式二：本地静态服务（推荐用于投屏演示）**

在本目录下执行任意一种：

```powershell
# Python
python -m http.server 8080 --directory prototype

# Node
npx --yes serve prototype
```

然后访问 `http://localhost:8080/`。

> 说明：原型刻意采用“传统脚本 + 哈希路由”的零依赖实现，目的是保证在任何评审环境下都能双击即开；生产版本按架构文档采用 React 18 + TypeScript + Tailwind CSS + Ant Design 5.x。两者页面结构、组件划分与交互流程一一对应。

## 四、演示路径建议（3 分钟走完）

> 界面按**成熟、正式、已上线的官方法律数据库**呈现：顶栏仅保留「首页 / 法律体系 / AI 问答」，首页只保留定位、检索入口与最新法规，其余功能已归位到检索页与法规详情页。

1. **首页**：Hero 检索框 → 切换「搜法规 / 搜案例 / 搜条约」三类内容，或点「高级检索 →」。
2. **M1 法规检索**：输入 `越南 外资 最低注册资本` → 结果卡片展示标题（多语言）、国家标识、法律层级、时效性与公布日期；左侧按「国家 / 法域」「主题」「法律层级」「时效性」勾选联动；**检索按钮右侧的「高级检索」**可就地展开面板，按制定机关、语言、检索方式、公布日期区间、施行日期区间精确限定（面板不弹窗、有高级条件时自动展开）；窄屏下筛选以底部抽屉弹出。
3. **案例 / 条约检索**：检索页切换到「搜案例」「搜条约」→ 进入案例详情页（审理法院、案号、裁判日期、案情摘要、相关法规）或条约详情页（签署/生效日期、缔约方、协定概要）。
4. **M2 法律体系**：顶栏「法律体系」→ 十二法域层级结构矩阵，观察普通法系/混合法系的判例法与伊斯兰法源标注；点任一法域进入国家详情页查看层级树与收录情况。
5. **M5 + M4 + M3**：任选一部法规进入详情页 → 正文中带下划线的术语**单击即可**查看多语种译法与释义（再次单击收起，悬停仅高亮不弹窗） → 右侧「法规工具」可直接「加入跨语言条款比对」「法律术语对照」并按需导出术语表；工具栏支持字号、深色模式、全文朗读、复制引用与导出 PDF。
6. **M6 AI 问答**：点建议问题（如「越南外资企业的最低注册资本要求是什么？」）→ 观察答案结构：法条概览 → **条文要点（每条带 `[n]` 引用）** → 法条依据（可点击回溯原文）→ 背景说明（非条文结论）→ 风险与提示；问带国别的问题（如「越南劳动法的试用期最长多久？」）验证**只引用该国条文**（不会拿别国法规顶替）；再问一个非法律问题（如「今天北京天气怎么样？」）验证**婉拒作答**并给出「您是不是想问」的 4 条相近法规问题（可点击直接重问）。侧栏「模型增强（自带 API Key）」为可选项，默认关闭、演示时无需配置；已支持 9 家 OpenAI 兼容服务商与「自定义模型 ID」。

## 六、数据说明（重要）

- **数据分四层，另有唯一权威存储**：
  0. **★ 权威存储 `data/laws/<法规ID>.json`**（**18,854 部法规，每法一个独立 JSON**，共 **18,857 个文件**；`data/laws/index.json` 为总索引，另有《无本地原文清单》《条号重复清单》两份 CSV）。**人工修订、采集入库只改这里**；下文的 `fulltext/`、`cn/`、`intl/` 分卷均为由 `_work/merge/build-packs.js` 从本目录**自动生成**的派生产物，请勿手工编辑。规范见 [rules/SKILL-条文入库与译文分离规范.md](rules/SKILL-条文入库与译文分离规范.md) §4.7；
  1. 元数据层 `dataset-core.js`（12 法域、法规元数据）；
  2. 扩展层 `dataset-extra.js`（术语 161 条、条约 18 项、案例 10 件、修订 12 条、问答 15 组）；
  3. **官方全文层 `data/fulltext/<法域>.js`**（直连各国官方法律数据库抓取的法规全文，逐条不节选，附来源 URL 与抓取日期）；
  4. **全量法规目录层 `data/cn-catalog.js` + `data/cn/cn-p01.js`…**（参赛队整理的中国法律法规汇编 **1,540 部 / 57,525 条 / 690.5 万字**，分 20 卷，打开具体法规时按需加载）；
  5. **东盟分卷层 `data/intl-catalog.js` + `data/intl/<国家>-pNN.js`**（各法域官方法律数据库抓取的条文全文，**逐条不节选、逐字照录官方语言**）。当前已落层 **11 法域 / 17,220 部法规 / 238,314 条条文 / 2.22 亿字**（252 卷），以新加坡（SG）为例：新加坡总检察署（Attorney-General's Chambers）《Singapore Statutes Online》官方打印视图 **3,714 部 / 56,624 条英文原文**（Act 527 部全部抓齐 + 附属法规 3,187 部），详见 [docs/19-新加坡法规入库实录.md](docs/19-新加坡法规入库实录.md)；泰国（TH）国务委员会办公室（OCS）官方检索系统核心层级 **697 部 / 27,820 条 / 1,121.3 万字泰文原文**，另 184 部（其中 175 部已废止）仅官方元数据、登记为目录条目并附官方详情页链接，详见 [docs/18-泰国法规入库实录.md](docs/18-泰国法规入库实录.md)。

- **法域全文层级口径**：法规条文层的**唯一真源为 `prototype/data/laws/<法规ID>.json`**（2026-10-08 两批数据合并后确立）；`prototype/data/{intl,cn,fulltext}/*.js` 分卷与 `rules/data/` 均为其派生产物（分别由 `node _work/merge/build-packs.js` 与 `node _work/export-law-articles.js rules/data` 生成）。各法域按官方层级枚举确定入库范围——泰国取 OCS `searchLawType` 的 `10`（宪法）/`1A`（宪法性组织法）/`1B`（法律）/`1C`（紧急敕令）/`1D`（法典）为核心层级全量抓取，其余次级规范（敕令 `2A`、部规 `2B`、公告 `2E`、地方法律 `2J` 等）本轮 OCS 公开索引未收录，待后续补录。
- 数据来源为各国官方法律信息门户的公开文本，逐条标注来源与抓取日期；译文与原文**物理分离**（D 层 `data/trans/`），界面读取时在内存中合并，从不写回原文。
- **译文层（D 层）现状**：**255 部中国法规 / 5,814 条英译**，分 13 个分卷（`cn.en` + `cn-p01.en`…`cn-p12.en`）。含《民法典》官方英译本（1,260 条，`engine=official`）与 254 部经 `calr-trans-v2` 契约产出的英译（`engine=llm`，标记 `reviewed: machine`）。每条译文保留 `provenance{engine, model, promptVersion, translatedAt, reviewed, glossaryVersion}`，出处另见 `prototype/data/trans/PROVENANCE.md`。法规详情页「阅读模式」可在**原文+译文 / 仅原文 / 仅译文**间切换。
- **法规标题中译**：全库 **17,985 部（95.4%）** 有中文标题（菲律宾 / 新加坡 / 中国 / 东帝汶 100%，文莱 97.1%）；无中文标题者在界面标注「原文标题 · 暂无当前语言译名」而非臆造译名。标题中译契约与工具链见 [rules/SKILL-法规标题中译规范.md](rules/SKILL-法规标题中译规范.md)（`calr-title-zh-v1`，13 条机器校验规则）；**译名归档在 [`prototype/data/title-zh/`](prototype/data/title-zh/)`** ——`titles.zh.json` 为全量导出（17,985 条）、`index.json` 为覆盖统计与 7 个交付批次、`artifacts/` 为任务包与回执包原始存档、`PROVENANCE.md` 记录译法与已纠正的质量事故。
- **语料库口径（对外统一表述，均为实测可核验数字）**：`prototype/data/laws/` 已收录 **12 个法域 18,854 部法规 / 334,681 条结构化条文 / 270,580,193 字**；条文原文涉及 **10 种语言**（英、中、泰、葡、高棉、越南、老挝、印尼、缅甸、马来）；**界面文案已实现 6 种语言**（中文、英文、越南语、泰语、印尼语、马来语，各 780 词条、缺失 0），**缅甸语、高棉语、老挝语界面待专业翻译后上线**。

## 八、已知边界

1. 原型覆盖 12 法域，但**官方全文的获取取决于各国门户的开放程度**：部分国家仅提供扫描件 PDF、需登录或需交互式检索，这些法规保留节选示意文本并在 `#/sources` 页面单列「待补官方全文」，不以节选冒充全文。
2. 官方文本以**本国官方语言**为准（如越南语、泰语、印尼语、马来语、老挝语）；已有译文者为 D 层 `data/trans/` 中 **255 部中国法规的英译（5,814 条）**，其余法规尚无译文，页面以「原文标题 · 暂无当前语言译名」明确标注语种，**不以机器翻译冒充实译**。
3. AI 问答在原型中默认由**本地规则化检索增强生成**实现（同一条链路：检索 → 引用 → 生成 → 溯源），生产环境替换为私有化大模型 + BGE-M3 向量召回 + 重排模型。
4. **BYOK 模型增强为可选功能，默认关闭**：用户可自带大模型 API Key（仅 OpenAI 兼容协议），Token 费用自付、自行填写接口地址；**未配置时页面不发起任何网络请求**，平台"零依赖离线"形态不变。启用后平台会执行**本地引用校验**，剔除无法回溯至本地条文的句子，校验不通过则自动降级为本地检索结果。该功能是本项目**唯一有意引入的网络出口**，相关成本与责任边界已写入「使用条款 / 隐私政策 / 免责声明」。
5. 界面多语种以中文为基准键，缺失译文自动回退中文原文。
6. 条款比对中的“制度衔接提示”由规则库生成，用于提示可援引的条约依据与争议解决路径，不替代个案法律意见。
7. 演示视频需由团队按 `docs/04-演示视频脚本.md` 自行录制（本仓库仅提供脚本与检查清单）。
