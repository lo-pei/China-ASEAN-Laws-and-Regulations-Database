## 二、译法约定

层级词按规范照搬：Act / Law → 法，Code → 法典，Order → 命令，Rules → 规则，Regulations / Regns → 条例，
Notification → 公告，Decree → 法令，Ordinance → 条例，Royal Kram → 王室敕令，Amendment → 修正。
年份与文号原样保留，并与中文之间留一个半角空格（`公司法 1967`、`植物检疫法，佛历 2507（1964）`）；括号改中文括号。

专有名词：公司名、人名、学校名、街道名、桥名、机场名一律保留英文；新加坡法定机构用其官方中文名
（会计与企业管制局、陆路交通管理局、市区重建局、建屋发展局等）；菲律宾省、市用通行中文译名。

## 三、两处需要知会的判定

**1）修了校验器的一个误判。** `FORBID` 原写法是裸匹配「略」，导致「战略 / 策略 / 简略」被判为 R9 套话——
菲律宾有整条法名含 "Strategic"（如 Strategic Environmental Plan），只能改译成别的意思来规避。
已改为只匹配独立的省略标记 `[（(]略[）)]`。改后六个既有回执包复验仍全部 PASS。

**2）R7（中文占比 ≥50%）与 R4（地名保留原文）在菲律宾长标题上互相冲突。**
菲律宾法案标题把「改设城市 + 省 + 市镇 + barangay + 校名」堆在一条里，同一地名常重复两三次；
严格保留全部专名时，R7 失败率约 10%（746 / 7,575），而这些条目在 90 字上限内无法靠译通用词补足。
最终口径：**行政地名（省 / 市 / 市镇 / Barangay / 村 / Sitio / 区）用中文音译，学校名、公司名、人名、
街道名、桥名、机场名保留英文。** 这是本轮唯一的规则偏离，如果要求地名也严格保留原文，
需要放宽校验器的 R7 阈值或在界面上改标注方式，请指示后我重跑这 746 条。
