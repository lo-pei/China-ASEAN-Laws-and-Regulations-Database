首页背景照片放置说明
====================

把东盟会议合照放到本目录，首页会自动使用它，无需改任何代码。

支持的文件名（按优先级探测，命中即用）：
  1. asean-summit.jpg
  2. asean-summit.jpeg
  3. asean-summit.png
  4. asean-summit.webp
  5. home-bg.jpg
  6. home-bg.png

建议规格：
  - 尺寸：1920 x 1080 或更宽（横向）
  - 体积：300 KB 以内（建议先压缩，避免拖慢首屏）
  - 构图：主体（人物/会场）尽量位于画面中上部，页面取景为 center 32%
  - 授权：请使用本单位自有、已获授权或公有领域的照片

若本目录没有上述文件，首页会回退为深海军蓝渐变底，文字可读性不受影响。
放置照片后会自动叠加一层压暗遮罩，以保证标题与检索框始终清晰可读。
