## 二、重新生成

当前**没有一条命令可跑通**的批量流水线：

- 旧脚本 `_work/build_docs.py` 的 `JOBS` 映射整体过期（仍指向旧文档集），直接运行会把本目录覆盖成旧集合。
- 正确做法：先修映射（按上表），再逐份渲染；渲染工具为 `_work/md2docx.py`。
- 改完 06 申报书（评分材料）或 05 视频脚本后，**必须重出对应 docx**，否则与 md 不一致。
