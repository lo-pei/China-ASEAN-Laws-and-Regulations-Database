# 两份 PDF 交付物 · 制作简报（v2）

> 提交系统**只接受 PDF**。因此：
> - **产品解决方案 Demo** = 一份**演示文档**（PDF）：演示目标、准备、逐幕操作、预期结果、真实截图、讲解话术。

> 二者是**两个独立交付物**，内容不互为翻版。Markdown 仅为源文件，最终交付 PDF。

## 三、交付物 A：`solution/产品解决方案Demo.md` → `产品解决方案Demo.pdf`

**定位**：答辩/评审现场照着就能演示的**演示文档**；不是使用手册，也不是方案论证。
**篇幅**：3,500–4,500 汉字；6–8 页；使用 5–6 张真实截图。

章节（H2）：
1. **这份 Demo 怎么用**：说明是演示动线文档；配合真实产品 `prototype/index.html` 使用。
2. **演示目标与准备**：目标（10 分钟内让评委看到“查得到、读得懂、引得对”）；环境（浏览器、`file://` 双击、无需网络/安装）；分辨率建议；备选（无网络/无 API Key 时看截图与说明）。
3. **演示总览**：四幕（检索 → 详情 → 比对 → 问答）+ 两个补充场景（术语、来源/引注）；3/5/8 分钟时间表。
4. **第一幕：法规检索**：操作步骤（打开首页 → 输入“民法典” → 查看首条）；预期结果（首条《中华人民共和国民法典》，卡片含国别/公布日期/条文数/来源）；截图 `search-results`；讲解要点（三种入口、多维筛选）。
5. **第二幕：法规详情**：步骤（点首条 → 原文与 AI 译文逐条对照 → 右侧条文目录 → 文内查找）；预期（1,260 条、109 章；第一条/第二条原文与英文译文）；截图 `law-detail`；讲解要点（译文分离、AI 标注、来源可核验）。
6. **第三幕：跨语言条款比对**：步骤（进入跨语言比对 → 点快速示例“中越外商投资准入对比” → 查看五维报告）；预期（中国《外商投资法》第四条 vs 越南《投资法》第九条；整体相似度 3%，显著差异；报告按适用范围/核心概念/法律后果/程序与期限/门槛与标准展开，可导出 CSV/打印）；截图 `compare-report`；讲解要点（原文并列、不输出“哪国更严”的结论）。
7. **第四幕：AI 智能问答**：步骤（进入 AI 问答 → 输入问题 → 阅读回答与条文引用）；说明（默认“API 配置 未启用”；需按提示配置自有模型 Key（BYOK）；没有 Key 时仍可用检索/比对，问答只返回检索依据，不生成虚构内容）；截图 `assistant`；讲解要点（每条结论附条文出处、AI 标注、可回溯原文）。
8. **补充场景与收尾**：术语对照（截图 `terms`：术语 214 条、73 条含 ≥5 语种）；数据来源核验（截图 `sources`）；规范引注（4 种格式）。
9. **讲解话术与时间控制**：给 3 分钟 / 5 分钟 / 8 分钟各一段可照读的话术（每段 80–120 字），并标注每幕时间。
10. **可复现与故障兜底**：纯静态打开方式；后端命令（建库 7 分钟、uvicorn）；7 个校验命令；现场故障时改用截图/离线页。
11. **附录**：截图索引、演示数据口径、文件位置。

要求：步骤写成“点哪里 → 看到什么 → 说明什么”；每幕都要有“预期结果”；不要写“点击 HTML Demo 页面”（HTML 版本不提交）。

## 四、交付物 B：`solution/产品使用说明书.md` → `产品使用说明书.pdf`

**定位**：给使用者/评委/部署者的**操作手册**；不是演示稿。
**篇幅**：5,000–6,500 汉字；11–14 页；使用 6–7 张真实截图。

章节（H2）：
1. **产品简介与适用范围**：是什么、面向谁、能做什么、不做什么（不提供法律意见/不替代律师/无判例检索）。
2. **快速开始**：① 纯静态（双击 `prototype/index.html`，3 步）；② 后端（建库 → 安装依赖 → uvicorn → 浏览器）；③ Docker/Windows（简要，指向 `docs/deploy/`）；系统要求与首次启动说明。
3. **界面总览**：顶部导航（首页/法律检索/跨语言比对/AI 智能查询/数据来源等）、语言切换、页脚；响应式说明；截图 `home-hero`。
4. **法规检索**：三种入口（关键词/自然语言/条号）、12 法域与主题/层级/时效筛选、排序、结果卡字段解释、分页；截图 `search-results`；提示（关键词空格、条号写法）。
5. **法规详情**：原文/译文切换、条文目录、文内查找、字号、朗读、导出；截图 `law-detail`；说明 AI 译文标注与原文优先。
6. **跨语言条款比对**：选择 2–3 个法域与条文或点快速示例、生成报告、五维阅读、导出 CSV/打印；截图 `compare-report`；提示报告只并列原文不下结论。
7. **AI 智能问答**：何时可用（配置模型 Key/BYOK）、提问方式、如何读引用与出处、无 Key 时的行为；截图 `assistant`。
8. **术语对照与规范引注**：术语搜索/领域筛选/CSV 导出（截图 `terms`）；引注 4 种格式（GB/T 7714-2015 / Bluebook / 简化式 / 完整式）与复制。
9. **数据来源核验**：来源页（截图 `sources`）、`source`/`sourceUrl` 字段、如何回官方页面核对。
10. **数据口径与阅读说明**：规模表；译文/标题/AI 标注；6 条数据红线；已知限制（向量滞后、39 部缺标题、325 部条号重复、判例未入库、缅甸 OCR、单 worker）。
11. **常见问题 FAQ**（至少 8 条）：打不开/白屏、加载慢、搜索无结果、问答无回答、译文为什么是 AI、能否离线、移动端、数据更新后怎么看、如何引用。
12. **部署与维护摘要**：Docker/compose、Windows、建库与校验命令、数据更新流程（指向 `docs/deploy/`）。
13. **免责声明**。
14. **附录**：文件结构、校验命令、术语表（可选）。

要求：以“操作步骤 + 界面元素 + 注意事项”为主；不要大段讲技术架构/融资/市场；不要写 Demo 讲解话术。

## 五、格式与验收

- Markdown（GFM 表格），中文；H1 只有标题，H2 为章节；图片占位单独一行；相对链接可用。
- 数字严格按事实表；真实法条只引用库内原文（可引用前一份说明书中的真实引文，但不要新编）。
- 完成后自检：字符数、章节数、表格、占位符、禁用词、与事实表一致性。
- 输出路径：`solution/产品解决方案Demo.md`、`solution/产品使用说明书.md`；**不要**修改其他文件、不要生成 PDF（Lead 统一构建）。
